# 城市柔光 v22(副本)

**experimental。** 入口 `v22-studio.html`,脚本 `layout-studio-v22.mjs`,样式 `layout-studio-v22.css`。
从 v21 复制后修改;**v21 的三个文件与全部 Blender 工程、GLB、烘焙数据均未改动**(哈希核对一致)。
v22 只读 `blender/city-14-studio-baked.glb` 与 `city-14-studio-plan.json`,没有重新烘焙。

## 噪点的原因与修法

v21 灯光模式里的蓝/青/紫细线和黑点不是烘焙数据的问题:烘焙顶点色全部非负、无 NaN、无溢出。
原因是 4× MSAA 在极细三角形(窗框、立面细条)上把顶点色插值**外推**到三角形外,
算出负值,经色调映射变成单通道为 0 的彩色像素。

- 顶点色改用 `centroid` 插值,采样点始终在三角形内;再钳到 [0, 1]。
- 实测(2000×1350,同一机位):异常偏色像素 v21 298 → v22 0;暗点像素 204 → 0。

## 四层光

| 层 | 做法 |
|---|---|
| 顶部大面积柔光 + 白色环境 | 沿用 Cycles 烘焙的漫反射光照 |
| 极浅阴影、纯白主体 | 着色器里按亮度抬亮暗部(`lift`),压掉水面/凹窗带来的青绿偏色(`sat`),统一偏暖乳白;Neutral 色调映射保住白色不发灰 |
| 局部暖光(只三处) | 最高 9 座塔楼朝镜头立面正中一道窄竖缝光;沿岸 22 栋低层建筑一层玻璃;主桥桥面下方水面与桥墩。暖色为淡香槟 / 暖白偏金 |
| 暖光扩散 + 轻辉光 | **不添加任何发光几何体**,暖光全部在建筑表面着色里出现:按立面范围限定,凸出的白框、竖条保持白色,凹处和玻璃才发暖光;建筑前地面轻微光晕;辉光只作用于暖光 |

第一版曾用凸出立面的发光细盒子做灯带和光条,放大后像灯管插在楼上,已全部移除。

暖光位置从 `plan.buildings` 的占地轮廓与锁定机位计算(取最朝向镜头的立面);桥边高度用射线在桥面网格上实测。

## 调参

URL 参数可临时覆盖默认值:`exposure`(1.1)、`lift`(.2)、`sat`(.45)、`warm`(1)、`spill`(1)、`bloom`(.16)。
例:`v22-studio.html?warm=1.4&lift=.3`。

## 限制

- 暖光是网页端叠加的近似,不是 Cycles 真实的光线传输;「Cycles 对照」仍是 v21 的离线图,没有这些暖光。
- 效果依赖锁定机位:暖光立面按当前视线方向选择。
- 仅在本机 RTX 5080 + Chrome 无界面模式截图核对;移动端、低端 GPU 与实际浏览器观感未验收。
