# 白模城市

这里是主站首屏那座白模沙盘的**制作端**。程序生成/AI 生成的装饰城市,
**不是真实墨尔本地图或房源**。

**当前状态(2026-09-21):烘焙路线已上线主站首屏。** 网页侧只有
`app/web/showroom/showroom.mjs` + 同目录的烘焙产物;架构见 `docs/ARCHITECTURE.md`
的「首屏白模沙盘」,为什么这么做见 `docs/DECISIONS.md` 的三条相关决定。

## 当前路径:离线烘焙(v26 → v28)

Blender 4.5 + Cycles/OptiX 把光烘成贴图,网页端无光照显示。**相机锁死**:
只能在烘焙时那个正交画框内平移缩放,不能旋转。

| 脚本(`blender/`) | 作用 |
|---|---|
| `render_v27_plinth.py` | 台座/沙盘场景与相机(在内存里搭,不存源文件) |
| `build_v28_houses.py` | 四套户型样板、草地、侧挂售房牌 |
| `bake_v28_showroom.py` | 宽幅烘焙主驱动,可断点续跑(`city-28-baked.blend`) |
| `render_v28_ids.py` | beauty + 对象 ID 层,用来修隐藏面漏出的细线 |
| `render_v28_shadows.py` | 桌面影子,城市 / 户型拆成两张 |
| `post_v28_layers.py` | 补空洞像素、替换隐藏面、生成接触阴影 |
| `export_v26_web.py` | 导出 GLB(Draco + WEBP)与树木 GLB |

- 成品去向:`app/web/showroom/`(GLB + 贴图 + 相机 JSON,约 17MB)。
- 中间产物:`bake-v28/`、`renders-v27`、`renders-v28`、`.blend` —— 体积大,
  **整个 `design/white-city/` 有 2.2GB,不要整目录入库。**
- 逐次实验参数与踩过的坑:`LIGHTING_V24_EXPERIMENTS.md`;
  工作流复盘(为什么前期一直做不出来):`RENDER_LESSONS.md`。
- 网页预览入口:`v28-showroom.html`(沙盘 + 户型转场)、`v26-baked.html`(只有城市)。

## 微动 01（路线已否决，仅存档）

- `city-motion.js` 只控制背景相对 HTML 前景的微动，不将建筑切片或变形。原图与静帧 HTML 的内容未修改；不宣称真实 3D 或分层深度重建。
- WAAPI 只动画 `transform`，单程 24 秒、48 秒往返，曲线 `cubic-bezier(0.77, 0, 0.175, 1)`；水平 ±0.65%、垂直 ±0.2%。固定放大 3.2% 留出边缘余量，不做呼吸缩放。
- 精细鼠标有上限 7px/3px 的额外视差，使用 mass 1 / stiffness 100 / damping 10 的弹簧；触摸不跟随，不移动文字和输入框。
- 手动暂停冻结当前位置，继续时接着播放；输入框内有焦点、页面隐藏或离开视口时暂停。`prefers-reduced-motion: reduce` 去掉位移与放大，保留静态可用页面。
- 优先原生合成动画。只有检测到原生时间线停住才启用 30fps 定时推进同一个 WAAPI 效果；本轮内嵌浏览器原生时间线正常，不能继续笼统认为所有内嵌动画都会冻结。
- 验证命令：`node tests/test_city_motion.cjs`。七项生命周期检查覆盖减少动态、暂停恢复、输入/隐藏、冻结时间线降级、正常时间线、不可用回退及触摸隔离；UI 需在浏览器继续验收观感。
- 浏览器已观察到实际位移，手动暂停后矩阵保持不变，输入时暂停、失焦恢复和鼠标小幅跟随正常；默认桌面、1536×864、390×844 已检查边缘覆盖和排版。

## v5 实时实现（保留对照）

- 斜向俯视相机与投影偏移，城市保持在文字下方；40×19 地块、局部错位、双组团天际线。
- 河前留白，沿岸布置展馆和退台建筑；减少桥数量，保留传送带运动及稳定的城市坐标树木采样。
- 大构件增加小倒角；树冠改为更小的簇状体；远处树木独立降精度。
- `scene.environmentIntensity` 控制场景环境光，材质分色、柔化方向阴影和 GTAO 保留白模层次。
- 暖光包括发光窗面、最多八盏局部点光源、地面光晕与选择性 Bloom。
- 后期顺序：Render → GTAO → Bloom → Output → 基于深度的背景融合。
  AO 开关只改变混合强度，深度持续更新；曝光不会改变最终空白背景色。
- 动画最高 30fps；暂停或隐藏页面时不持续重绘。HUD 三角形数包含一帧的多个渲染 pass。

## v5 验证与限制

JS 模块语法检查、浏览器着色器编译与暂停/AO/灯光开关检查通过；八个现有后端验收脚本通过。
默认桌面与 1536×864 构图已核对。独立浏览器 GPU 帧率、低端设备及手机布局尚未验收；
内嵌预览可能节流，不能用其 HUD 数字断言正常浏览器性能。

目前仍是模块化实时白模，未实现离线全局光照、精细定制建筑资产或完整水面反射。
视觉与性能验收前，不把它记录为已完成的主站功能。
